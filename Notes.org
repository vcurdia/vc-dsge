* 2016-08-18: Aux-Parameters that require numerical solution
If there are aux-parameters that require a numerical solution conditional on
the parameter values then we can proceed as follows.

Create 
m.NumSolveParam with the following fields:
- Names: list of parameter names that link to AuxParam
- Fcn: system of equations to solve. Each equation (function element) is a
  function of elements of AuxParam
- Guess: vector with guess of solution for each NumSolveParam
- Solution: solution of csolve
- rc: return code from csolve

In doing this I need to create AuxParamFcn which will evaluate AuxParam for a
given guess of NumSolveParam.

Once solution is achieved then can map AuxParam to the output of that function.

If length of m.NumSolveParam.Names is zero (empty) then this step is skipped.
